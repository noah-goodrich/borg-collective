borg link: one sweep, one document

Every invocation reads the world once, then hands it to code that cannot read the world at all. The boundary is what lets the picture be pinned against hand-authored fixtures.

ONE SWEEP, TWO CONSUMERS — `--brief` makes the same `--json` call every other arm makes, feeds it to `claude -p`, and on failure pipes those same bytes back through `--render-document`. Never re-derive; never rebuild for the fallback.
