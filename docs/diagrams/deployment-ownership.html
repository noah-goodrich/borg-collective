Borg: who installs what, where

Three producers, disjoint targets. If you have read a doc saying skills install to ~/.claude/skills/, this is why that is no longer true.

ONE EXCEPTION — Cortex Code (CoCo) has no plugin system, so CoCo skills still install from $BORG_HOME/skills via `cortex skill add` (borg setup, step 3). That is the only case where a skill installs outside the plugin.
