## Verified Quote(s)

Metrics section:

> compared to percentage agreement, Cohen’s κ was better able to distinguish between LLM-evaluators.

Binary outputs:

> Thus, where possible, I have my evaluators return binary outputs.

> If using direct scoring, can you simplify the task to binary (e.g., true/false)?

Pairwise:

> If it’s subjective, pairwise comparisons will likely be more reliable.

Biases:

> During pairwise comparisons, LLM-evaluators tend to prefer the response in one position over others.

> verbosity bias, where LLM-evaluators favor longer, more verbose responses

> Finally, self-enhancement bias, where LLM-evaluators preferred answers generated by themselves.

## Key finding

Yan's survey recommends chance-corrected agreement (Cohen's kappa) over percent agreement for validating judges, binary outputs for objective criteria, and pairwise comparison for subjective ones. It documents position, verbosity and self-enhancement bias as recurring across studies.
