## Key finding

When judged on objective correctness of hard response pairs (knowledge, reasoning, math, coding) rather than human preference, many strong judges perform barely above chance. This is contrarian evidence against using an LLM judge where correctness is checkable: a deterministic check or executed test should be preferred.
