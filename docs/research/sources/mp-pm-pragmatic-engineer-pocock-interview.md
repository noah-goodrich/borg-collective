## Key Findings

- grill-me was inspired by Anthropic's Thariq Shihipar, who shared an approach of an agent interviewing its user; Matt turned it into a skill.
- Matt noticed agents build software layer by layer, causing bugs between layers; the Pragmatic Programmer's 'tracer bullet' term made agents produce better code, and he now reads classic books for more 'leading words'.
- He frames the human role as 'strategic' programming (Ousterhout) and agents as tactical.
- He has mixed feelings on TDD with agents and now asks for proof the code works, with or without TDD.
