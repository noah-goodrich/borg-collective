## Key Findings

- Anthropic hosts the pack in its Claude Marketplace as a Claude Code plugin by Matt Pocock; the page lists "21 composable agent skills".
- The marketplace install counter read 1,745 on 2026-10-13, a first-party figure that is orders of magnitude below the "18 million installs" some blogs report (which come from the skills.sh route and are not verified).
- The "Anthropic verified" badge appears on other plugins in the same strip (Frontend Design, Code Review, Code Simplifier) but not on Pocock's page or on Superpowers, so neither is Anthropic-endorsed.
- Counts of skills in the pack differ by source and date (21 here, 25 in the manifest per VarOps, 37 in the repo), so star and skill counts need dating when cited.
