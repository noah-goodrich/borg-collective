## Key Findings

- AI Hero presents the skills as 'a practical skill system', grouped Getting Started, The Main Flow, Shaping, Engineering, Productivity Skills and Reference Skills, with a changelog of six entries from 2026-04-30 to 2026-10-05.
- The page's own Claude Code install line is claude plugins install mattpocock-skills (read-only managed plugin, updates automatically), differing from the README's marketplace-qualified command: expect command drift across Matt's own surfaces.
- Changelog timeline: Apr 30 (Ubiquitous Language became grill-with-docs), May 11 (handoff, prototype, review), Jun 18 (v1.0, '63% token reduction', ask-matt), Jul 8 (v1.1 wayfinder, to-spec, to-tickets), Aug 5 (v1.2 wait-what, writing-for-agents, Claude Code plugin), Oct 5 (v1.3 implement-spec, pr, retro, GLOSSARY.md).
- The featured-skills list still shows /to-prd and /to-issues, the pre-v1.1 names, showing that even the primary marketing page lags the renames.
- AI Hero also exposes agent-readable discovery files (llms.txt, markdown twins, an API), signalling the site is built to be consumed by agents.
