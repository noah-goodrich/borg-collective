## Key Findings

- A user ran Superpowers and Pocock's pack side by side, then deleted Superpowers' hooks because it "overcomplicated simple problems".
- Reports that the Q&A of /grill-with-docs used fewer tokens than Superpowers' brainstorming "with no worse results" (self-reported, unmeasured).
- Uses a split-model flow: an expensive model writes the PRD and issues on GitHub, a different model implements; stored artifacts make it easy to resume.
- Says the explicit-invocation model returns the "when to use which skill" decision to the user.
