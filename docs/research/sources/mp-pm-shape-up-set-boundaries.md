## Key Findings

- Appetite is a time budget set before design: 'Estimates start with a design and end with a number. Appetites start with a number and end with a design.'
- Fixed time, variable scope forces trade-offs about what is core.
- If the work cannot fit the appetite, narrow the problem or walk away; a '2.0' grab bag without a defined 'done' is a warning sign.
- Neither the to-tickets nor the wayfinder skill contains an appetite or time budget; their only size limit is one context window.
