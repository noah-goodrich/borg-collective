## Key Findings

- Observed beginners learning Visual Basic .NET; identified six barrier types: design, selection, coordination, use,
  understanding, information.
- Each name points at a different remedy (e.g. selection = which tool/API to use; coordination = how pieces combine).
- Treats 'stuck' as a typed event rather than one lump.
- Taxonomy was derived from observation of one population; not a validated instrument.
