## Key Findings

- Defines cognitive offloading as using physical action to change a task's information-processing demands and reduce cognitive load (e.g. programming a phone reminder).
- Offers a metacognitive framework: offloading is triggered by beliefs about internal capacity, not just by actual capacity.
- Not ADHD-specific: transfer to adult ADHD is an inference this track makes, not a finding of the paper.
