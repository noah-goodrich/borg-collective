## Key Findings

- A UK EPSRC-funded 'Rethinking Project Management' network (2003-2005) formed because of 'the growing critiques of
  project management theory' and set out five directions: project complexity, social process, value creation, project
  conceptualisation and practitioner development.
- These directions overlap the areas PMBOK 7/8 and PRINCE2 7 later added or emphasised (complexity,
  stakeholders/people, value, tailoring, leadership), suggesting the mainstream decomposition has been converging
  toward its critics for 20 years.
- The paper is an agenda, not an evaluation: it provides no evidence that any alternative decomposition outperforms
  the classic one.
- Only the abstract was available; the full text is paywalled (see paywalled candidates).
