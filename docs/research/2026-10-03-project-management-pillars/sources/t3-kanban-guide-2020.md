## Key Findings

- Defines four minimum flow measures: WIP, Throughput, Work Item Age, Cycle Time. Work Item Age is the only one that applies to in-flight work.
- WIP must be explicitly controlled, often via WIP limits, which creates a pull system. The wording is 'often', not 'always' (the limit is a means to explicit control).
- Introduces the Service Level Expectation (period + probability) as a forecasting-by-percentile device rather than an average.
- The Guide contains no empirical evidence that these practices improve outcomes; it is a definitional standard (feeds RQ2 as a practice description, not proof).
