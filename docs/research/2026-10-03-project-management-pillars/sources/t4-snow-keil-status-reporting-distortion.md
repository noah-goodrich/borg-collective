## Key Findings

- Reported status can differ from true status for two separable reasons: manager perception errors and deliberate bias
  before reporting; the combination is "project status distortion".
- The model's results say most software projects are already in trouble early, managers are overly optimistic, and
  executives receive status reports very different from reality.
- Practical conclusion: executives should be skeptical of favourable status reports, and for higher-risk projects
  should focus on reducing reporting bias.
- This is modelled evidence from expert elicitation, so the magnitude is not an empirical base rate for any real
  population; only the abstract was accessible.
