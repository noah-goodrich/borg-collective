## Key Findings

- Betting is a periodic (once per cycle) decision meeting over a few shaped pitches, explicitly not a groomed backlog;
older ideas are revived only if someone champions them.
- Appetite is a value-derived time budget set before design; it inverts estimation (number first, design second), so
effort becomes a cap instead of a forecast.
- The circuit breaker is a default-no-extension stopping rule: an unfinished bet is not extended, which the authors say
eliminates runaway projects and bounds the cost of a wrong bet.
- Betting is deliberately one cycle ahead so the organization keeps options open; true crises are asserted to be very
rare.
- Evidence is experiential only: no data on whether betting beats scoring methods, so it supports "what a documented
practice is", not "that it improves outcomes".
