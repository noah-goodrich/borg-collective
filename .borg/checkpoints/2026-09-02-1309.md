**The GitHub question, answered by execution rather than reading.** A 10-agent workflow (5 investigation dimensions →
design → 4 adversarial lenses; all four found real defects) plus direct experiments established:

- **E1 never needed GitHub at all** — it needed a second private repo on disk. `shell.discover` is `os.listdir` +
  `open`, zero subprocess. Proven by building two ephemeral repos with `git init` + `git remote add origin`: real slugs
  (`acme/platform`, `acme/warehouse`) resolve with **zero network**, because `git remote get-url` is a `.git/config`
  read. `repository_slug` needs git; it does not need the wire.
- **E3's coupling is incidental** — GitHub is its input, not its assertion. The real pipeline over an empty recon
  document returns `declared 14, contested [], dangling 17`: the case passes against a completely failed sweep.
- **E2's coupling is essential but narrow** — one bit per ref ("does it exist, can this token see it"). The other eight
  ref properties are already enforced offline by `borg_core.manifest`.

**Root cause was not GitHub.** `run.sh` hardcoded `/Users/noah/dev/borg-collective`; `HOME` is `/Users/noahgoodrich` and
`/Users/noah` does not exist. With `set -uo pipefail` and **no `-e`**, the prologue's `mkdir -p "$OUT"` failed silently
and all five cases reported FAIL for never having run. One commit in its history, never touched since.

## 4. Blockers

No blockers. Three things carried forward:

- **AC6 is not closed.** `PROJECT_PLAN.md`'s verify clause still names `make eval --skip-model`, which can never work —
  make's getopt consumes any leading-dash word before a goal is built. Needs a ratified amendment in AC7's form, and it
  must carry a **zero-selection floor**: a green run that selected zero cases is a failure. That absence is why
  "deterministic cases green in CI" sat at zero members across three checkpoints unnoticed.
- **A time bomb tied to work already in flight.** E3's `program_contested_refs == []` becomes unfalsifiable when AC7
  removes the last top-level `program` key: `merge-tree/gather.py:187` skips any manifest without one, and
  `borg_core/manifest/shell.py:108` writes `_id` and is pinned never to invent `program`
  (`test_shell.py`: `assert "program" not in without_key`). Measured — stripping the key gives `contested []` even with
  a real collision injected. Green because the code stopped running. Recorded as a comment in `run.sh`.
- **E4/E5 grade `/pr-description`, which this repo does not own** — nothing under `skills/` matches it; it is a
  claude-plugins skill. AC5 sequencing, not a GitHub problem.
