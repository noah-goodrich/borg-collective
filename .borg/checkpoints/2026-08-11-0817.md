- **#114** — **fixed red main.** All 5 failures were one root cause: `bsd || gnu` `stat` chains. On GNU, `-f` means
  *filesystem status*, so `stat -f %m FILE` prints a filesystem block **to stdout** and only then exits nonzero —
  the fallback fires and command substitution captures `File: "…" … 1786418121` concatenated, so arithmetic under
  `set -u` dies with `File: unbound variable`. Reversed to GNU-first (clean: BSD `stat -c` fails with empty
  stdout). `_borg_has_recent_checkpoint` had no fallback at all — returned "no recent checkpoint" unconditionally
  on Linux. Fixed in `borg.zsh` (`_borg_file_mtime`, `_borg_has_recent_checkpoint`), `lib/recon.sh`,
  `hooks/borg-link-up.sh`.
- **#113** — **`borg recon` was inert under zsh since #95.** Two bugs: `BASH_SOURCE` is empty in zsh so
  `_recon_lib_dir` resolved to `.`; and zsh doesn't word-split unquoted expansions so `IFS=:; set -- $var` yielded
  one element. Now verified live: *"swept 16 github repo(s) — 4 PR item(s), ok: true"*.
