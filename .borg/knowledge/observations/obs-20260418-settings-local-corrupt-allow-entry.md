# obs-20260418-settings-local-corrupt-allow-entry

## content

`.claude/settings.local.json` (generated by `borg setup`) contains a corrupt entry in the Bash allow-list on line 22: a sentence fragment that appears to be a commit message accidentally injected into the JSON permissions array. The entry reads `"Bash(matters most\" — all research citations preserved, narrative shifted from deficit framing:*)"`. This does not break JSON parsing in the versions tested but is semantically wrong and could cause unexpected permission grants if the allow-list is evaluated by prefix matching.


## resolution

Manually delete the corrupt line from `.claude/settings.local.json` before committing the file. Treat any future allow-list entries that read as natural language prose as an indicator that a commit message was accidentally pasted into the wrong buffer during a `borg setup` or similar interactive step.
