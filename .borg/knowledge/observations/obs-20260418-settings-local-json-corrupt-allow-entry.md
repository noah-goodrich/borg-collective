# obs-20260418-settings-local-json-corrupt-allow-entry

## content

`.claude/settings.local.json` (generated by `borg setup`) contains a corrupt allow-list entry on line 22: a prose sentence fragment ("Bash(matters most\" — all research citations preserved, narrative shifted from deficit framing:*)") was accidentally written into the permissions array, likely copy-pasted from a commit message during an earlier interactive session. The file is untracked and not committed, so it poses no upstream risk, but it will cause unexpected permission-check behaviour if the entry is ever evaluated by the Claude plugin.


## resolution

Remove the fragment entry from the array in `.claude/settings.local.json`. No functional regression expected — the entry matches nothing real.
