# 20260731-interactive-session-nonrecording-by-design

## decision

Interactive-session non-recording judged by-design rather than a gap to fix

## context

Issue #46 gap 3 observed that 0 of 380 sessions over 7 days self-recorded. The question was whether this was a bug, a gap, or intentional.

## reasoning

Interactive sessions are not in scope for automatic self-recording. The observation requires confirmation but the current working hypothesis is this is intentional architecture, not a missing feature.
