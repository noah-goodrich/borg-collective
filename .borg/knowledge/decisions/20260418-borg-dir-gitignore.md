# 20260418-borg-dir-gitignore

## decision

Add `.borg/` to `.gitignore` alongside existing exclusions for `registry.json` and `.borg-project`

## context

.borg/ is a runtime state directory generated by borg tooling. It was previously unignored, risking accidental commits of ephemeral state.

## reasoning

Runtime/ephemeral directories are analogous to already-ignored artifacts in the repo. Committing them would pollute history with machine-specific state.
