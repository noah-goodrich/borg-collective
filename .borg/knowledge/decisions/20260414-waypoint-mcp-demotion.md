# 20260414-waypoint-mcp-demotion

## decision

Demote MCP server from primary surface to optional power-user integration for Waypoint. Mobile-first Next.js PWA is now the primary surface.

## context

v0.2.0 plan was Snowflake/MCP-first. That plan is now severed following the Snowflake exit decision.

## reasoning

MCP-first optimizes for a power-user niche before validating core user value. PWA-first reaches a broader audience and validates faster.
