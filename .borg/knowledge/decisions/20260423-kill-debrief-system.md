# 20260423-kill-debrief-system

## decision

Remove the auto-generated debrief system (Sonnet call in `hooks/borg-stop.sh`). Replace debrief reads in `borg-start.sh` with the newest checkpoint file. Update `borg link` and `borg init` to surface checkpoint data instead of debriefs. Delete `~/.config/borg/debriefs/`.

## context

Debriefs are generated by a Sonnet call at session end and summarize the session for the next session's context. Once checkpoint discipline is solid, the debrief adds latency and cost without adding information that checkpoints don't already contain.

## reasoning

Checkpoints are more granular, already exist, and are authored in-session rather than synthesized at the end. The debrief is a redundant synthesis layer.
