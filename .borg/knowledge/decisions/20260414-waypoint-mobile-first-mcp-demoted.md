# 20260414-waypoint-mobile-first-mcp-demoted

## decision

Demote MCP server to optional power-user integration for Waypoint. Mobile-first Next.js PWA is now the primary surface. v0.2.0 Snowflake/MCP-first plan cancelled.

## context

v0.2.0 plan had MCP as primary surface. Pivot away from Snowflake forced re-evaluation of the entire product surface hierarchy.

## reasoning

MCP-first assumes a power-user developer audience before product-market fit is established. Mobile-first PWA reaches a broader initial cohort and validates core value faster.
