# 20260609-80-20-verb-by-verb

## decision

After proving the reaper slice, file 3–4 separate directives for remaining verbs (scan/scoring, cairn-client, search) each parented to the original extraction plan — one verb at a time rather than batching them.

## context

PR #41 demonstrated the 80/20 plugin self-containment pattern works. Multiple other verbs have the same duplication problem but tackling them together would be high-risk.

## reasoning

Each verb has its own coupling surface; parallel extraction risks merge conflicts and makes rollback harder. One-at-a-time keeps PRs reviewable and failures isolated.
